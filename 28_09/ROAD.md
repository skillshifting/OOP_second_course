# 3. D — Dependency Inversion Principle

> Классы должны зависеть от абстракций, а не от конкретных реализаций.

Делать только после завершения S.

- [ ] Определить зависимости каждого класса
- [ ] Создать интерфейсы для необходимых зависимостей
- [ ] Использовать `ABC`
- [ ] Использовать `@abstractmethod`
- [ ] Не передавать конкретные реализации, если можно передать интерфейс
- [ ] Передавать зависимости через конструктор или метод
- [ ] Убрать создание зависимостей из рабочих классов
- [ ] Почти каждый рабочий класс должен реализовывать интерфейс согласно требованиям работы

Пример проверки:

```text
Плохо:
ClassA сам создаёт ClassB

Хорошо:
ClassA получает необходимую абстракцию через конструктор
```

# 4. I — Interface Segregation Principle

> Класс должен получать только те методы интерфейса, которые ему действительно нужны.

- [ ] Проверить каждый созданный интерфейс
- [ ] Не создавать один огромный интерфейс для хранилища
- [ ] Если классу нужен только `add` — дать ему интерфейс только для добавления
- [ ] Если классу нужно только чтение — дать ему интерфейс только для чтения
- [ ] Если классу нужен только вывод — дать ему интерфейс только для вывода
- [ ] Разбить слишком большие интерфейсы на маленькие
- [ ] Ни один класс не должен зависеть от ненужных ему методов

---

# 5. O — Open/Closed Principle

> Код открыт для расширения, но закрыт для изменения.

Главное место для проверки — выбор типа партии.

- [ ] Найти `if/elif`, который определяет тип создаваемой партии
- [ ] Убрать необходимость изменять основной сценарий при добавлении нового типа партии
- [ ] Вынести создание разных типов партий в отдельные реализации
- [ ] Сделать возможность добавить новый тип партии новым классом
- [ ] Проверить, что при добавлении третьего типа партии старые классы почти не нужно менять

# 6. L — Liskov Substitution Principle

По условию работы отдельно сложную реализацию делать не требуется.

- [ ] Проверить корректность наследования
- [ ] Наследники `Party` должны нормально использоваться вместо `Party`
- [ ] Не нарушать контракт родительского класса
- [ ] Не делать наследнику неожиданное поведение относительно родителя
