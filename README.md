## Модульное тестирование (Unit Testing)

**Unit Testing** — автоматизированное тестирование отдельных классов и методов программы независимо от остальных компонентов.

Для тестирования используются стандартные библиотеки Python:

- `unittest` — создание и запуск модульных тестов.
- `unittest.mock` — подмена зависимостей тестируемых классов.
- `MagicMock` — создание mock-объектов с заранее заданным поведением.
- `patch` — временная подмена функций и объектов, например `input()` и `print()`.

### Основные проверки

| Метод | Назначение |
|---|---|
| `assertEqual(a, b)` | Проверка равенства значений |
| `assertIs(a, b)` | Проверка идентичности объектов |
| `assertTrue(x)` | Проверка истинности значения |
| `assertFalse(x)` | Проверка ложности значения |
| `assertIsInstance(a, B)` | Проверка принадлежности объекта классу |
| `assertRaises(Error)` | Проверка возникновения исключения |
| `assert_called_once_with(...)` | Проверка единственного вызова с указанными аргументами |
| `assert_has_calls(...)` | Проверка выполненных вызовов |
| `assert_not_called()` | Проверка отсутствия вызовов |
| `call_count` | Количество вызовов mock-объекта |
| `subTest()` | Проверка нескольких случаев внутри одного теста |

### Mock-объекты

**Mock** — подставной объект, имитирующий поведение реальной зависимости.

Используется для изолированного тестирования: проверяется только ответственность тестируемого класса, а не работа всех его зависимостей.

Например, при тестировании `PartyFilter` настоящий `RequiredFirstLetterChecker` заменяется на `MagicMock(spec=FirstLetterCheckerInterface)`.

**Основные настройки:**

- `spec` — ограничивает mock интерфейсом или классом.
- `return_value` — задаёт возвращаемое значение.
- `side_effect` — задаёт последовательность ответов, функцию или исключение.
- `call` — описывает ожидаемый вызов метода.

### Что тестируется в программе

|---|---|
| `Party` и наследники | Хранение и получение данных |

| Creators и CreationFlow | Создание партий и взаимодействие зависимостей |
| Formatters | Правильность форматирования и выбор форматтера |
| `PartyPrinter` и `ConsoleOutput` | Формирование и передача текста на вывод |
| `PartyInputScenario` и `Task` | Корректность взаимодействия компонентов |
